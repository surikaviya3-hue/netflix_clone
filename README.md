# Netflix Clone

## Project Overview
This project is a Netflix Clone web application that replicates the core functionality and interface of the Netflix streaming platform. It demonstrates full-stack development, API integration, and responsive UI design.

- **Frontend:** Vite (Fast and modern frontend development)
- **Backend:** Spring Boot (Handles server-side logic and API requests)
- **Database:** Aiven (Stores user and application data)
- **API Integration:** TMDB API (Fetches movie and TV show details such as posters, titles, and descriptions)

## Features
- Responsive homepage with multiple movie categories
- Dynamic fetching of movie posters and details using TMDB API
- Backend API endpoints to manage and serve data
- Fully functional full-stack application

## Technologies Used
- **Frontend:** Vite, HTML, CSS, JavaScript
- **Backend:** Spring Boot, Java
- **Database:** MySQL
- **APIs:** TMDB API
- **Tools:** Postman (for testing API), Maven (build automation)
